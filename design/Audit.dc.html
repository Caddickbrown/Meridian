STYLING REVIEW

What the current design system is doing to you

Ten findings from src/app/globals.css (2,491 lines), page.tsx and the panel components. Ranked by how much each one costs you.

TYPE FLOOR
7px to 11px
BRAND HUES
17 to 1 + 2
GLOBAL TRANSITION
600ms to 140ms
FLOATING PANELS
6 edges to 3 docks
MAX TRACKING
0.40em to 0.10em
BACKDROP BLUR
24px to none
01
Every element in the app animates four properties for 600ms
* { transition: background-color .6s, border-color .6s, color .6s, box-shadow .6s; }
FIXA universal selector over a WebGL map that repaints constantly. It is why hovers feel like wading. Scope transitions to interactive elements at 140ms, panels at 240ms, and delete the global rule.
02
Seven-pixel type, set in 0.2em tracking
.hud-label { font-size: 7px; letter-spacing: .2em; text-transform: uppercase; }
FIXNobody reads this; they recognise its shape and guess. Set an 11px floor for machine labels, 13px for anything with words in it, and let the grid do the compressing instead of the point size.
03
Seventeen hues compete, and gold means two things at once
gold + cyan brand · 4 alert colours · 11 map-layer colours
FIXGold is the brand and also reads as caution, so escalation has no colour of its own. Move the brand to one cold accent, then warm hues mean only one thing: something is going wrong.
04
The map is boxed in on all six edges
header TL · status TR · layer rail L · tool rail R · view controls BL · ticker B
FIXSix floating islands, none aligned to another, each with its own radius and shadow. Collapse to three docks — top bar, left column, bottom strip — and give the globe three clean edges to breathe on.
05
Glassmorphism over a moving map
.glass-panel { backdrop-filter: blur(24px) saturate(1.3); border-radius: 14px; }
FIXBlur is expensive over WebGL, and it softens exactly the thing this product sells: dense, legible numbers. Opaque surfaces, one-pixel hairlines, one shadow token.
06
Depth is signalled with brand colour
.osiris-glow { box-shadow: 0 0 20px gold/.12, 0 0 60px gold/.06; }
FIXIf elevation is gold, gold cannot also mean state. Elevation goes neutral; colour is reserved for data.
07
Monospace is doing the work of a typeface
JetBrains Mono on labels, values, nav, buttons, headings, tooltips
FIXMonospace earns its place in tabular figures and machine identifiers. Everywhere else it is a costume. Archivo for interface, IBM Plex Mono for numerals and codes only.
08
Letter-spacing used as hierarchy
tracking-[0.4em] · [0.3em] · [0.2em] · [0.18em] · [0.15em]
FIXFive tracking values carry no information — weight, size and colour already do. Keep one value, 0.1em, on one class of label.
09
Ghost Protocol is a find-and-replace, not a theme
body.theme-ghost { --gold-primary: #B388FF; /* 23 more remaps */ }
FIXA variable called --gold-primary holding violet is a token system admitting defeat. Rename to intent — --signal, --surface-2, --escalation — and a theme becomes a decision rather than a substitution.
10
The stylesheet is decorated
/* 🔥 THEME TRANSITION SYSTEM 🔥 */ · ══════ rules · 2,491 lines
FIXCosmetic, but it is the tell. This system was dressed rather than designed, and the ten findings above are what that costs at runtime.

None of this is a data problem. The feeds, the endpoints and the map are the hard part and they already work. What is failing is the layer between them and the eye — and that is the cheapest thing in the stack to replace.
